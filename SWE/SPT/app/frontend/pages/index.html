What is SPT?

SPT, or Secure Password Tool, is a web-based password generation and management tool. The application will allow users to create an account, generate cryptographically secure random passwords, and save & manage passwords.

How to use SPT?

  1. Click on the "Use Password Generator" button. You do not need to create an account to begin using SPT. However, making an account will allow users to manage passwords.
  2. Select the number of passwords you would like to generate, ranging from 1-5 at a time.
  3. Select the number of characters you would like each password to contain, ranging from 10-15 characters.
  4. Once the selections are made click the "Generate" button, and BAM! Cryptographically secure random password(s) are generated.
